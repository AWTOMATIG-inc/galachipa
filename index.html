Project Summary: This is a single unified project consisting of two layers — a public-facing website for institutional presence, and a backend management system (EMS) for day-to-day administration. The goal is to reduce manual paperwork, enable parent communication via SMS, and centralize all institutional data. এটি একটি সমন্বিত প্রকল্প। প্রতিষ্ঠানের পরিচিতির জন্য পাবলিক ওয়েবসাইট এবং দৈনন্দিন প্রশাসনিক কার্যক্রমের জন্য একটি ব্যাকএন্ড ম্যানেজমেন্ট সিস্টেম — দুটি একসাথে।
